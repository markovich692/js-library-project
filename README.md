# Library

A Library application built as part of The Odin Project curriculum.

The goal of this project is to strengthen my understanding of JavaScript objects, constructor functions, prototypes, and inheritance by creating a system that allows users to manage a collection of books.

## Concepts Practiced

- Object creation and manipulation
- Constructor functions
- Prototypal inheritance
- Object methods
- DOM manipulation
- Event handling
- JavaScript fundamentals

## Technologies Used

- HTML
- CSS
- JavaScript

## Learning Goals

This project focuses on understanding how objects are created and linked through prototypes, how constructor functions work, and how JavaScript's inheritance model enables objects to share behavior efficiently.
